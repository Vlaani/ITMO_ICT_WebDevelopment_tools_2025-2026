Endpoints

Варианты

  • GET /api/variants — получить список всех вариантов

  • POST /api/variants — создать новый вариант

  • GET /api/variants/{variant_id} — получить конкретный вариант по ID

  • PATCH /api/variants/{variant_id} — обновить вариант по ID

  • DELETE /api/variants/delete/{variant_id} — удалить вариант по ID

Атрибуты

  • GET /api/attributes — получить список всех атрибутов

  • POST /api/attributes — создать новый атрибут

  • GET /api/attributes/{attribute_id} — получить атрибут по ID

  • PATCH /api/attributes/{attribute_id} — обновить атрибут по ID

  • DELETE /api/attributes/delete/{attribute_id} — удалить атрибут по ID

Товары

  • GET /api/products — получить список всех товаров

  • POST /api/products — создать новый товар

  • GET /api/products/{product_id} — получить товар по ID

  • PATCH /api/products/{product_id} — обновить товар по ID

  • DELETE /api/products/delete/{product_id} — удалить товар по ID

Пользователи

  • GET /api/users — получить список всех пользователей (только админ)

  • GET /api/users/{user_id} — получить пользователя по ID

  • PATCH /api/users/{user_id} — обновить данные пользователя по ID (только админ)

  • GET /api/me — получить данные текущего авторизованного пользователя

  • PATCH /api/me/update — обновить данные текущего пользователя

Заказы

  • GET /api/orders/my — получить список заказов текущего пользователя

  • POST /api/orders/create — создать новый заказ

  • POST /api/orders/cancel/{order_id} — отменить заказ по ID

Аутентификация

  • POST /api/register — регистрация нового пользователя

  • POST /api/login — вход в систему (получение токена)

Модели

ProductAttributeLink

  • product_id (PK): int

  • attribute_id (PK): int

VariantAttributeLink

  • variant_id (PK): int

  • attribute_id (PK): int

Attribute

  • id (PK): int

  • name: str

  • value: str

OrderVariantLink

  • order_id (PK): int

  • variant_id (PK): int

  • quantity: int

Order

  • id (PK): int

  • user_id (FK): int

  • created_at: datetime

  • status: Enum (OrderStatus)

  • total_price: int

Product

  • id (PK): int

  • name: str

  • description: Optional[str]

User

  • id (PK): int

  • login: str (unique)

  • username: str

  • email: str (unique)

  • password: str

Variant

  • id (PK): int

  • price: int

  • stock: int

  • product_id (FK): int

Подключение к БД

Файл: db.py

import os
from sqlmodel import SQLModel, Session, create_engine
from dotenv import load_dotenv

load_dotenv()
db_url = os.getenv('DB_ADMIN')
engine = create_engine(db_url, echo=True)

def init_db():
    SQLModel.metadata.create_all(engine)

def get_session():
    with Session(engine) as session:
        yield session
